## English

SahaGo is a full-stack football pitch booking application that allows users to search for available pitches by district, date, and time, create bookings, and manage their reservations.

The backend is built with ASP.NET Core Web API and Entity Framework Core. The frontend uses React and TypeScript, while application data is stored in Microsoft SQL Server.

### AI-Generated Project

This project was built entirely through AI-assisted development. All application code, tests, database migrations, documentation, and architectural structure were generated by AI under human direction and review.

No application code was written manually. My role was to define the requirements, guide the development process, review the generated results, and provide feedback.

> Payment operations use a FakeSandbox provider and do not involve real money transfers.
